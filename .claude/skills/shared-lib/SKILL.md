# shared / sharedlib

`shared/` is a uv package named `sharedlib` that sits in the repo root next to
the services. Every service installs it as an editable path dependency. The
complete starting point is in `templates/shared/` next to this file.

## Layout

```
shared/
├── Makefile              # env, test, lint
├── pyproject.toml        # name = "sharedlib", packages = ["sharedlib"]
├── .python-version
├── README.md
├── uv.lock               # generated by `uv sync`
├── sharedlib/
│   ├── __init__.py       # empty
│   ├── base_handler.py   # BaseHandler: ServiceException → ServiceResponse, ends DB session
│   ├── exceptions.py     # ServiceException(code, message, errors, params)
│   ├── db_config.py      # engine, Session, Base, IdMixin, CreatedMixin, CreatedUpdatedMixin
│   ├── service_client.py # ServiceClient(source).call(method=, destination=, request=)
│   ├── exchanges.py      # EXCHANGE_<SERVICE> constants
│   ├── results.py        # ok_result / error_result for `*_result` messages
│   └── testing.py        # create_test_database() for DB-backed tests
└── tests/
    ├── __init__.py
    ├── test_base_handler.py
    └── test_service_client.py
```

## Creating it

1. Copy `templates/shared/` to `<repo>/shared/` (include `.python-version`).
2. Replace the placeholders:
   - `__PROJECT_TITLE__` - human project name, e.g. `Agency Helper`.
   - `__DATABASE_URL__` in `sharedlib/db_config.py` - the local default, e.g.
     `postgresql+psycopg://<user>:<pass>@localhost:<port>/<db>`. Use the same
     value as `DATABASE_URL` in `.env.example`.
3. Add one `EXCHANGE_<SERVICE>` constant to `exchanges.py` per service that
   exists.
4. Run `uv sync` in `shared/`, then `make test`. Report the result.
5. Wire it into the root `Makefile`: `shared` is first in `SERVICES` and first
   under `env`.

## How services use it

```toml
[project]
dependencies = ["sharedlib"]

[tool.uv.sources]
sharedlib = { path = "../shared", editable = true }
```

- Handlers subclass `sharedlib.base_handler.BaseHandler`, not mrkutil's, and
  raise `ServiceException(code, message)` for expected errors.
- `app/models/__init__.py` imports `Base` and `Session` from
  `sharedlib.db_config` before importing the models.
- `db_config` reads `DATABASE_URL` and `MAX_THREADS` from the process
  environment at import time, so a service's `settings.py` must
  `os.environ.setdefault(...)` both before anything imports the models.
- A service calls another one with
  `ServiceClient(settings.EXCHANGE_<SELF>).call(...)`, only towards services
  lower in the dependency graph, never in a cycle.
- Dockerfiles copy the folder with `COPY shared /shared` (see the
  `service-dockerfiles` skill).

## What belongs here

Put code in `sharedlib` only when at least two services need the same thing
and it has no dependency on one service's models: enums stored in more than one
service, permission tables, validators, exchange names. Each goes in its own
module (`enums.py`, `permissions.py`, `<topic>_validation.py`) with a test file
`tests/test_<module>.py`.

Keep out of it: anything mrkutil already provides, models, handlers, and
settings classes. `sharedlib` has no `settings.py`; it reads the few values it
needs from `os.environ`.

A stateless service must be able to import `sharedlib.base_handler` without
creating a database engine, so never import `db_config` from `base_handler`,
`exceptions`, `service_client` or `results`.

After changing `shared/pyproject.toml` dependencies, run `uv lock` in every
service, because each service's `uv.lock` pins sharedlib's dependencies too.
